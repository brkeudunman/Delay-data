# 02b — Top-5 SHAP features

**Question.** The LLM top-5 arms ([06.1](../06_1_llm_top5_datafree/README.md),
[06.2](../06_2_llm_top5_datainformed/README.md)) cost 2–4 AUC points against all features,
but had no SHAP counterpart with the same feature budget. Is that loss due to having only
five features, or to the LLM picking the wrong five?

**Feature set** (`features.mode: shap_only`, `top_shap_n: 5`): the first 5 rows of
`shap_feature_importance.csv` from `02_2020_train` (2020 training days only):
**O_LONGITUDE, O_LATITUDE, CRS_ELAPSED_TIME, O_TEMP, D_LONGITUDE**, all continuous.
For comparison, the LLM top-5 sets are categorical-heavy: data-free = OP_CARRIER, ORIGIN_INDEX,
CRS_DEP_TIME_MIN, O_PRCP, O_WSPD; the data-informed set shares only ORIGIN_INDEX and O_PRCP with it.

Separate arm rather than `--set features.top_shap_n=5` on 02: `top_shap_n` is not in the
runner's skip key, so such runs would collide with 02's top-10 rows.

Training settings: `../common/base_config.yaml`, no overrides (`common/check_configs.py`: OK).

```bash
A=exp/Tab_exp/ablations/02b_shap_top5
M="--models MLP,AutoInt,ResNet,FTTransformer,LightGBM,XGBoost,CatBoost"
uv run python $A/run.py $M --seed 42                         # Phase 1 + seed 42
uv run python $A/run.py $M --seed 43 --reuse-params          # and 44
uv run python $A/run.py $M --seed 42 --reuse-params --set training.phase2_frac=1.0   # 43, 44
```

## Findings (3 seeds, target `abs`, test base rate 0.424)

AUC, mean over seeds 42/43/44. Seed std of the 02b cells ≤ 0.0055, except AutoInt with
the final fit on all of train (0.011).

- **SHAP top-5 beats both LLM top-5 sets on every model, at both training sizes.** At 10%
  of train, the margin over the better LLM set is +0.059 (MLP), +0.045 (ResNet), +0.014
  (AutoInt), +0.006 (FT) and +0.030 (each GBDT). All but FT are far outside the seed std.
  FT's margin is about one std, though 02b is ahead on every seed (0.6147 / 0.6042 / 0.6112
  vs 0.6038 / 0.6027 / 0.6046). At full train the margins are +0.022 to +0.077. So the LLM
  arms' loss comes mostly from *which* five features the LLM picked, not from having
  only five.
- **Going from 10 to 5 SHAP features** costs AutoInt / FT-Transformer 0.008–0.016 AUC at
  10% of train and 0.025–0.033 at full train; the GBDTs move by −0.011 to +0.002. MLP gains
  at both training sizes (+0.012 at 10%, +0.014 at full train) and is then the best MLP of
  all arms. ResNet gains at 10% (+0.006) and loses at full train (−0.023).
- With 10% of train, SHAP top-5 matches the LLM *top-10* on the GBDTs (0.633–0.636 vs
  0.631–0.636) and beats it on MLP and ResNet.
- Average precision (base rate 0.424) ranks the arms the same way. At 10% of train: SHAP
  top-5 0.508–0.545, LLM top-5 0.443–0.520, all features 0.500–0.556.
